# 批量移入超时：v0.4.1

## 实际定位

2026-10-23 在用户内置浏览器检查已安装的浮动面板，旧日志为：15:37:11 开始批量移入8个；15:37:31 报“等待超时：批量移入待发布”，批次停止并标记待核对。该文本来自旧 adapter 寻找菜单项的20秒等待，并不是60秒的“移入结果”等待。不能仅据此断言这次已经提交了8条移动请求。

采集箱真实操作中，Playwright 点击“批量操作”有时不能让菜单显示；真实鼠标点击后显示。菜单 DOM 是 `.ant-dropdown .batchOperationDropdown .menu-item`。新代码增加鼠标移入事件，并明确将这一步超时标为“尚未提交”。

旧版移动命令内部只等待60秒出现标题“执行结果”，工作流没有独立的移动进度等待和数量核验。新版本将提交与进度轮询分开，只有最终统计覆盖本页全部商品、成功数量吻合且失败为0，才关闭最终弹窗、跳转待发布。进度100%、状态“已完成”本身不能当作最终结果。等待15分钟仍无完整结果、连接中断或最终含失败，保留当前页面并停止自动化；不会自动重试移动。后台另加 pendingMove 导航保护。
