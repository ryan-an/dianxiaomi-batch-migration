### 已确认字段选择器

| 表格字段 | DOM 定位 |
|---|---|
| Parent SKU | `input[placeholder^="示例：华为P60"]`，placeholder 也出现在外层 div 上，必须限定 input |
| UPC | `input[placeholder="必填项，Prodcut ID"]`（页面实际拼写如此） |
| 品牌 | 标签“品牌”内的 combobox，输入后 Enter 提交 |
| 制造商 | `input[placeholder="请输入制造商"]` |
| Model Number | `[id="form_item_model_number.0.value"]` |
| Model Name | `[id="form_item_model_name.0.value"]` |
| Price | `input[name="price"]` |
| List Price | `[id="form_item_list_price.0.value_with_tax"]` |
| Color | `[id="form_item_color.0.value"]` |
| 商品长宽高 | `form_item_item_dimensions.0.{length,width,height}.value` 及 `.unit` |
| 包装长宽高 | `form_item_item_package_dimensions.0.{length,width,height}.value` 及 `.unit` |
| 包装重量 | `form_item_item_package_weight.0.value` 及 `.unit` |

带点的 ID 必须用属性选择器或 getElementById，不能直接拼 CSS #id。
