# 美国站填写与图片规则

版本：v0.4.36。按2026-10-27用户要求适配，上传工作簿仅作为业务数据读取，不修改原文件。

## List Price和价目表货币

- List Price使用表格同名列，与Price独立；不将Price列作为缺失金额的替代值。美国优先使用不含税价目表list_price.0.value，兼容含税价目表。
- 美国价目表货币选择USD(美元)。字段尚未挂载时等待加载，最多30秒，不能立即把异步出现的字段记为不存在。
- 先按字段路径和固定ID定位，再按准确标签定位；忽略隐藏的旧分类输入框。填写后重新定位当前节点回读，丢值或节点替换时最多重试3次，禁用、只读、写入不保留均记录错误。
- 提交前优先核对这两个字段，补回空值或错误值，再检查其他字段。
- 现场确认商品184807703390207417的两个路径为list_price.0.currency和list_price.0.value，页面货币唯一选项显示USD(美元)。该商品此前的执行日志把两个字段均记为跳过，随后发布失败。

## 站点与标题

- “US”和“美国”双向等价，兼容小写、首尾空格及全角US。解析后执行站点统一为“美国”，原始单元格保留。
- 认领店铺、列表匹配及编辑页身份核对均使用相同等价规则，不把店铺名称里的US或普通英文单词的一部分当成站点。
- 与德国共用标题规则：使用同一行“德国标题翻译”完整替换标题，忽略“产品数量”。字段名继续为“德国标题翻译”，不需要改表头。
- 翻译为空时该行报错；旧批次恢复时也会校验，不使用采集标题或其他列作为替代。

## 描述与卖点

- 产品描述完整替换为“德国标题翻译”，使用CKEditor公开接口同步正文与隐藏表单值，并回读核对。
- 第一条Bullet Point替换为同一内容，其余全部清空；扫描全部条目，不限于五条。
- 提交前再次检查并补齐描述和卖点。表格文本中的尖括号及HTML片段按纯文本处理。
- 品牌、制造商、型号、尺寸等沿用现有字段填写规则；美国价目表货币为USD(美元)，德国仍为EUR，英国仍为GBP。

## 删除附图和裁剪

- 美国不论“新品”为“是”、“否”、空白或缺失，都执行图片处理。其他站点继续只在“新品=是”时执行。
- 字段填写后、发布前，保留第一张主图并逐张删除后续附图；核对首图地址，避免删除主图。
- 从主图悬浮菜单打开“小秘美图”，裁剪宽、高均设为400，点击“应用”，再选“保存并应用”。所有站点的新品尺寸也统一改为400×400。
- 回到原商品表单确认仅一张400×400主图和更新后的图片地址。原来的一张300×300图片会重新处理；已经一张400×400时直接核对通过。
- 发布前再次核对图片数量和尺寸。图片失败或未确认应用时阻止该条发布，保留页面并继续下一条。
