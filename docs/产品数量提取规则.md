# 产品标题中的数量提取规则

更新日期：2026-10-24。用户已确认：多个数量取最前面一个。此规则替代上一版“不同数量冲突时留空”的处理。

## 1. 最终规则

从左到右扫描整个标题，返回**第一个符合下列格式的数量**，找到后立即返回：

- `Set of N`：取后面的 N。
- `N Pack / Packs / Pc / Pcs / Piece / Pieces`：取前面的 N。

不同关键词不设优先级，只比较出现位置。例如 `6 Pack Cups, Set of 12 Brushes` 返回 6；`Set of 12 Paint Sets, 24 Pcs Paintbrushes` 返回 12。

数量返回正整数；没有支持的数量表达式时返回空字符串 `""`。不默认填 1，不返回 0，不相加或相乘，不把包装数换算成内部件数。

## 2. 写法兼容

- 忽略大小写：`PCS`、`Pcs`、`pcs` 均支持。
- 支持数字与单位连写、空格、连接号：`4Pack`、`4 Pack`、`30-Pack`。
- 全角数字和字母做 NFKC 归一化；常见连接号统一为 `-`。
- 扫描范围包括标题末尾、括号内以及 `|` 后。
- Pack 等单位必须完整匹配，不从 `Package`、`Packing`、`Packed` 等单词内部提取。
- 仅识别正整数，并检查 JavaScript 安全整数范围。小数、负数、范围、乘法包装表达式、英文数字词、千位分隔数字不做数量换算，也不截取数字尾部。

## 3. 排除项与边界

颜色、尺寸、长度、容量、重量、年龄、功能、型号等不在数量白名单中：`12 Colors`、`7 Inch`、`16.5Ft`、`2 oz`、`100 lb`、`Age 3-12`、`7-In-1`、`(007)` 均不单独产生数量。

**“最前面”指最前面的有效数量表达式。** 裸数字仍沿用最初规则，不做推断：

- `7 Inch Tongs ... (5 Pieces)` 返回 5。
- `2 in 1 Pumice Stone ... 6 Pack` 返回 6。
- `100 Hard Bristle Pipe Cleaners ... 2Pcs ... Set of 5` 返回 2，因为 100 没有支持的数量单位。如果业务需要这条返回 100，应另加裸数字识别规则。

`Roll/Rolls`、`Bundle/Bundles`、`Pair/Pairs`、`Pad/Pads`、`Count`、`Sheet/Sheets` 当前没有加入函数。`5 Rolls`、`3 Bundles`、`3 Pairs`、`14 Pads` 单独出现时留空。

## 5. 函数位置与调用

函数已加入 `extension/core.js` 并导出，插件脚本可直接调用：

```javascript
DXMCore.extractProductQuantity('13 Pieces Clay Tools and 4 Pieces Dotting Tools'); // 13
DXMCore.extractProductQuantity('Set of 12 Paint Sets, 24 Pcs Paintbrushes'); // 12
DXMCore.extractProductQuantity('Garden Flag'); // ''
```

Node.js 调用：

```javascript
const { extractProductQuantity } = require('./extension/core.js');
```

函数已接入插件：采集后记录原标题和原标题数量；编辑页按上传表的“产品数量”替换标题里第一个有效数量的数字，回读确认后更新结果标题。库存数量仍按原流程清空。

## 7. 插件接入与结果下载（v0.4.20）

1. 采集标题对应到原表链接后，立即保存原标题及提取数量。
2. 编辑页完成其他字段填写后，按表格“产品数量”替换标题首个有效数量。只替换数字，保留原有单位、大小写、空格、连接号、尺寸、颜色和后续配件数量。
3. 读取当前标题确认写入结果，最多重试 3 次；页面重绘后重新查找输入框。后续身份校验与结果表使用当前实际标题。
4. 继续执行时同时兼容原标题和已修改标题；产品 ID、来源链接、店铺、站点仍须匹配。
5. 表格产品数量为空或标题未匹配时保留原标题并记录日志；非正整数的输入在表格解析时记为数据错误。
6. 标题写入失败沿用已有“字段警告后继续填写、检查及发布”规则，导出实际读取到的标题，不把计划标题当作写入成功。

下载结果固定为用户确认的 8 列：执行状态、原表链接、最终标题、原标题数量、表格产品数量、实际店铺、站点、失败原因。数量列为数字或空，详细执行日志仍在插件内保留。

例如采集标题为 `Set of 12 Paint Sets, 24 Pcs Brushes`，表格产品数量为 3，最终标题为 `Set of 3 Paint Sets, 24 Pcs Brushes`；下载表中原标题数量为 12、表格产品数量为 3。
