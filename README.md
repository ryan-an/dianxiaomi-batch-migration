## 安装和开始

1. 解压发布 ZIP，打开 Chrome 的扩展管理页 `chrome://extensions`（Edge 为 `edge://extensions`）。
2. 打开“开发者模式” → “加载已解压的扩展程序”，选择包含 `manifest.json` 的 `extension` 文件夹。
3. 在安装扩展的同一个浏览器里登录店小秘，再刷新店小秘页面。
4. 网页内会出现“店小秘迁移助手”浮动面板。上传或拖入 `迁移数据.xls`；按住标题栏可以拖到合适位置。
5. 点击“开始执行”，**默认处理整张表**。插件自动匹配店铺、选择当前或最近使用的店小秘标签页，直接提交链接采集，没有范围和映射设置。
6. 面板显示进度和日志；结束后点击“下载结果”，得到 XLSX，采集ID和产品ID保留为文本，避免 Excel 改写长数字。
7. 点击网页其他位置不会关闭面板。右上角“×”可关闭面板，通过工具栏插件图标重新打开；执行过程中不可关闭。面板会记住位置。

从旧版更新：使用新版完整的 `extension` 文件夹，在扩展管理页点击“重新加载”（或重新选择该文件夹），关闭旧控制窗口并刷新店小秘页面，再点击插件图标。不要在批次运行过程中更新。

## 已确认的填写规则

- 表格 `万万欣UK|英国` 固定映射到实际店铺 `[英国]万万欣DE`，其他店铺按原表店名和站点匹配。
- Sheet1 最后4条链接与 Sheet2 的4行数据按顺序补齐，结果保留两个来源位置；结构不一致就报错。
- UPC 去掉首尾空格，保留文本标识符；数字0属于有效数据。其他空单元格跳过。
- 先清空“价格信息”中的产品数量，再切换配送为 FBA。此处指库存，不是产品属性中的 Number of Items。
- 型号名称 Model Name 沿用同一行 Model Number（用户已确认），优先使用原表的独立 Model Name。品牌取原表“品牌”。
- 原产地 China（中国）、需要电池 No（不）、危险商品规管仅 Not Applicable（不适用），按用户图片填写。
- 英国 List Price 对应页面 `List Price with Tax`；长度单位中的德语 `Zentimeter(厘米)` 与英国 `Centimetres(厘米)` 作为同一单位匹配。
- 采集会留下无起止日期的促销价，这会阻止发布；插件清除这种不完整促销价并记入日志。已有完整起止时间的促销不改。

## 批次和错误处理

- 同店铺、同站点分组，链接以换行分隔，批量采集；失败项按当前页批量重试一次。
- 只勾选本批次产品，翻页处理，始终核对原链接、采集标题、采集 ID 和产品 ID；标题不是平台保证唯一的键。
- 采集前不扫描历史记录，也不按历史记录跳过链接；采集完成后按来源链接对应标题和采集ID。
- 同一来源匹配多条、店铺/站点不一致或缺字段，会停止该条或该店铺组并记明步骤，不猜数据。
- 发布成功弹窗出现即记录“已发布”并完成本条；不再查询在线或发布失败列表。未成功的表单校验仍记录失败。
- 页面用户点击和键盘操作在执行期间被锁定，点击停止并等待当前步骤结束后解除锁定。自动化生成的 DOM 事件仍可执行；浏览器地址栏、关闭标签等浏览器自身行为不受页面控制。
- 点击停止后不会启动新步骤；已经提交给店小秘的操作可能继续由服务器处理，插件不进行回滚或重复提交。
- 批次与阶段保存点保存在 `chrome.storage.local`。刷新后可点击“继续执行”，保留日志并跳过已确认阶段；提交结果不明时先提示核对。只有更换表格或清空缓存才重置批次。
